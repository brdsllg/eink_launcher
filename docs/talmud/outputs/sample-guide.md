# Talmud Bavli pilot sample set

Pilot books for testing on the Bigme. This is not the complete 37-tractate collection.
The EPUBs contain whole tractates; the amudim below are the spots to test.

## What the pilot contains

- Hebrew/Aramaic with the William Davidson (Steinsaltz) English beneath it.
- Rashi (or its tractate-specific substitute), Tosafot, and the Steinsaltz notes.
- One EPUB per tractate, one XHTML document per amud.
- Vowel points included; cantillation stripped.

## Test spots

| Tractate | Amud | Why |
|---|---|---|
| Berakhot | 2a, 2b | Opening passage, dense Rashi and Tosafot, baseline |
| Bava Metzia | 2a | Case-law passage, dense Tosafot |
| Bava Batra | 29a | Rashbam replaces Rashi from here |
| Sanhedrin | 96b, 97a | Narrative content, Steinsaltz notes |
| Tamid | 25b | Smallest tractate; anonymous commentator in the Rashi slot |
| Shabbat | 73a | The 39 categories of work; heavy commentary |

## What to check on the device

1. First-open import time for each tractate.
2. Page-turn speed with commentary showing.
3. Hebrew/Aramaic display: vowel points, right-to-left, font.
4. Commentary: tap the notes link, then go back.
5. Contents navigation by amud.
6. Search: enter a Hebrew word; check the result count and that results navigate.

For the full device checklist see `../docs/reader-device-findings.md`. Checksums are
generated with each package run and are not recorded here.
