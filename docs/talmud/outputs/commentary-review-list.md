# Talmud commentary review list

Every commentary source in the catalog, for manual review. Ticked = currently included; unticked = waiting for your decision. To change anything, say which titles to add or drop and the catalog (`talmud/outputs/source-selection.json`) gets updated — never edit that file by hand.

Total: 124 sources — 111 included, 13 waiting review.

Note: the included set is only Rashi (+Rashbam/Mefaresh substitutes), Tosafot, and Steinsaltz per tractate. If Sefaria lists further Bavli commentaries, they never made it into this catalog — that discovery check is still open (see the scale-up plan).
